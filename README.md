# Telkom University Company Profile - Praktikum 
 
Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git.
Perubahan ini dibuat dari simulasi Laptop B.
## Cara Menjalankan Project

1. Jalankan Apache dan MySQL melalui XAMPP.
2. Pastikan folder project berada di `C:\xampp2\htdocs\telkom-company-profile`.
3. Buka phpMyAdmin dan pastikan database `telkom_profile` tersedia.
4. Buka project melalui browser:
   `http://localhost/telkom-company-profile/`
5. Untuk halaman Program Studi:
   `http://localhost/telkom-company-profile/program.php`
6. Untuk halaman Berita:
   `http://localhost/telkom-company-profile/news.php`
